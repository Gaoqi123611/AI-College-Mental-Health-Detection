# 数据集说明文档
## 目录结构
dataset/
├── public_dataset/          # 公开数据集
│   ├── b_depressed.csv      # 抑郁标签数据集
│   
└── self_build_dataset/      # 自制数据集
    └── college_student_mental_self_build.csv # 200条大学生情绪文本

## 数据说明
1. 公开数据集：包含抑郁/焦虑/正常文本数据，用于模型基础训练。
2. 自制数据集：200条匿名大学生情绪文本，标签分为正常/轻度焦虑/中度抑郁/重度抑郁，贴合校园场景。

## 合规说明
所有数据仅用于本项目研究，无个人隐私信息，禁止商用。
